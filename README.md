# ナビアン先生シールメーカー

A4全面シール用紙に、先生からのひとこと入りシールを自由に配置して印刷するための静的Webアプリです。

## 使い方

1. 「ナビアン図鑑から選ぶ」で、ナビキャラ公開サイトの画像を選びます。「ナビキャラ」（6人）、「ナビアン」「エボナビ」「ボスナビ」の分類と名前検索が使えます。
2. 必要に応じて「手元の画像も追加できます」から、PNG/JPG/WebPなどの画像を読み込みます。
3. 使いたい画像を選び、コメントを入力して「シールを追加」を押します。
4. 「同じシールを追加」や「シートを同じシールで埋める」も使えます。
5. 用紙の向き、シールの大きさ、外側の余白、シール間隔、形を調整します。
6. 「印刷する／PDF保存」から印刷、またはPDFとして保存します。

## ナビキャラ画像について

- ナビアン・エボナビ・ボスナビの画像一覧データを参照し、画像本体はナビキャラ公開サイトから直接読み込みます。
- シールメーカー側に画像ファイルを複製・再アップロードしないため、素材サイトで画像が更新された場合も、公開パスが変わらなければ最新画像を利用できます。
- 画像を選ぶと、シールメーカー内で選択画像として保持されます。手元の画像を使う方法も残しています。
- 素材の利用条件は、ナビキャラサイトの利用ガイドを確認してください。

## 印刷について

- A4全面シール用紙向けです。ラベル位置が固定されたシートではなく、余白・サイズ・間隔を調整して自由に並べます。
- 印刷ダイアログではA4、倍率100%／実際のサイズを指定してください。
- プリンターの印刷可能領域は機種によって異なります。最初は普通紙で位置合わせを確認してください。
- 印刷プレビューに表示される細い輪郭線は、シールを切り分ける目安です。

## データとプライバシー

- 選んだ画像を外部サーバーへアップロードすることはありません。ナビキャラ画像を使う場合は、公開サイトから画像を表示するための通信が発生します。
- 「データを保存」で、画像URL・コメント・設定を同じ端末のブラウザ（localStorage）に保存できます。
- 手元の画像を読み込んだ場合、その画像データもブラウザ内に保存できます。ブラウザのデータ削除や別端末では保存内容を引き継げません。

## 技術

HTML / CSS / JavaScriptのみ。ビルド、APIキー、外部API、外部ライブラリは不要です。GitHub Pagesで公開できます。
