# ナビアン先生シールメーカー

A4全面シール用紙に、先生からのひとこと入りシールを自由に配置して印刷するための静的Webアプリです。

## 使い方

1. 「画像を選ぶ」からナビアンの画像（PNG/JPG/WebPなど）を読み込みます。複数選択できます。
2. 使いたい画像を選び、コメントを入力します。
3. 「シールを追加」でシートに配置します。「同じシールを追加」や「シートを同じシールで埋める」も使えます。
4. 用紙の向き、シールの大きさ、外側の余白、シール間隔、形を調整します。
5. 「印刷する／PDF保存」から印刷、またはPDFとして保存します。

## 印刷について

- A4全面シール用紙向けです。ラベル位置が固定されたシートではなく、余白・サイズ・間隔を調整して自由に並べます。
- 印刷ダイアログではA4、倍率100%／実際のサイズを指定してください。
- プリンターの印刷可能領域は機種によって異なります。最初は普通紙で位置合わせを確認してください。
- 印刷プレビューに表示される細い輪郭線は、シールを切り分ける目安です。

## データとプライバシー

- 画像の読み込み・編集・印刷はブラウザ内で行います。画像を外部サーバーへ送信しません。
- 「データを保存」で、画像・コメント・設定を同じ端末のブラウザ（localStorage）に保存できます。
- ブラウザのデータ削除や別端末では保存内容を引き継げません。画像を大量に読み込むと保存容量の上限に達する場合があります。

## 技術

HTML / CSS / JavaScriptのみ。ビルド、APIキー、外部API、外部ライブラリは不要です。GitHub Pagesで公開できます。
